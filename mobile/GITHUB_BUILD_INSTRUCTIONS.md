# بناء LinguaBridge كملف APK عبر GitHub

هذه الحزمة تحتوي تطبيق Expo أصليًا متوافقًا مع **SDK 57**. أضف محتويات هذا المجلد إلى مستودع GitHub **خاص**، ثم افتح تبويب **Actions** وشغّل سير العمل **Build Android Preview APK**. سيولّد GitHub ملف APK تجريبيًا مستقلًا، لذلك لن يعتمد التثبيت على Expo Go أو نفق التطوير.

| الخطوة | ما ينبغي فعله |
| --- | --- |
| 1 | أنشئ مستودعًا خاصًا باسم مثل `linguabridge-mobile`. |
| 2 | ارفع كامل محتويات هذا المجلد، بما فيها `.github/workflows/build-android-preview.yml` و`pnpm-lock.yaml`. لا ترفع `node_modules` أو `.expo` أو مجلد `dist`. |
| 3 | افتح **Actions** في المستودع، واختر **Build Android Preview APK** ثم **Run workflow**. يمكن أيضًا أن يبدأ تلقائيًا بعد الدفع إلى الفرع `main`. |
| 4 | عند ظهور علامة النجاح الخضراء، افتح نتيجة التشغيل ثم قسم **Artifacts** ونزّل `LinguaBridge-Android-preview-APK`. |
| 5 | انقل الملف إلى هاتف Android، وافتحه، ثم وافق على خيار التثبيت من هذا المصدر عندما يطلب النظام ذلك. |

> ملف APK الناتج **نسخة معاينة Debug** موقعة بمفتاح Android الافتراضي الآمن للتجارب الداخلية فقط، وليست نسخة متجر Google Play. قبل النشر العام يجب إعداد توقيع إصدار خاص بالحساب، وربط خدمات الاجتماعات والصوت الفعلية.

## ما الذي يتحقق منه سير العمل؟

ينفذ المسار تثبيت الاعتماديات المقفلة، وفحص TypeScript، وتوليد مشروع Android الأصلي من Expo، ثم تجميع APK. إذا فشل أي جزء ستظهر رسالة مفصلة في سجل GitHub Actions يمكن مشاركتها لمعالجتها.
