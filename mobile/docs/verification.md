# تحقق تطبيق الجوال الأولي

تم تجميع تطبيق Expo للويب بنجاح، ثم فتحه في متصفح للتحقق من الشاشة الرئيسية والانتقال إلى ردهة الجلسة. ظهرت هوية LinguaBridge العربية، الدعوات، النص والترجمة المتوازيان، وخيارات لغات الحديث والعرض، مع زر اختبار الميكروفون وحالة الموافقة.

| المسار | النتيجة |
| --- | --- |
| `/` | شاشة بداية متجاوبة مع انتقالات للإعدادات والردهة والمحضر |
| `/lobby` | اختيار لغة الحديث ولغة العرض والموافقة قبل بدء الاجتماع |
| `/meeting` | انتقل التدفق من الردهة بعد تفعيل الموافقة، وظهرت المقاطع الأصلية والترجمة وعناصر الكتم والنص الحي والرسالة |
| `/minutes` و`/settings` | ظهرت إجراءات المحضر والخصوصية، ثم اختيارات اللغة والصوت ومفاتيح الموافقات والتذكير |
| فحص TypeScript | ناجح عبر `pnpm check` |
| تجميع Expo Web | ناجح عبر `npx expo export --platform web` |
| تشخيص Expo | اجتازت الحزمة 18/18 فحصًا عبر `npx expo-doctor` |

تبقى صلاحيات الصوت الأصلية، الاتصال الجماعي الآني، ومزامنة API المنشور خطوات تكامل لاحقة لا يمكن التحقق منها من معاينة الويب وحدها.

يستخدم التطبيق `expo-audio` لطلب صلاحية الميكروفون وتهيئة جلسة الصوت في الردهة، ثم لبدء/إيقاف التقاط صوت محلي في غرفة الاجتماع. لا تُرسل التسجيلات ولا تُحفظ كمحتوى اجتماع قبل ربط قناة النسخ والترجمة الخادمية وسياسة الموافقة الإنتاجية.
