 # 🌍 LinguaBridge

 ### تكلّم بطبيعتك. وافهم الجميع.

 **LinguaBridge** هو منصة اجتماعات متعددة اللغات مدعومة بالذكاء الاصطناعي، تهدف إلى إزالة حاجز اللغة بين الأشخاص والفرق والعملاء من مختلف أنحاء العالم.

 تسمح المنصة للمشاركين بالدخول إلى **غرفة اجتماع خاصة واحدة**، بينما يحصل كل مشارك على المحادثة بلغته المفضلة، مع تصميم معماري يدعم الترجمة الفورية النصية والصوتية مستقبلًا.

 > **غرفة واحدة. لغات متعددة. محادثة واحدة.**

---

 ## 🎯 فكرة المشروع

 في الاجتماعات الدولية، غالبًا ما تكون اللغة عائقًا أمام التواصل الطبيعي.

 تم تصميم LinguaBridge لحل هذه المشكلة من خلال توفير بيئة اجتماع يستطيع فيها كل مشارك:

 - 🗣️ التحدث بلغته الخاصة.
- 🌍 تحديد دولته بشكل مستقل عن اللغة.
- 💬 اختيار اللغة التي يريد استقبال الترجمة بها.
- 🤖 الاستفادة من الترجمة بالذكاء الاصطناعي عند تفعيلها.
- 🔊 استقبال الترجمة صوتيًا في المراحل القادمة.
- 🎥 المشاركة في اجتماعات صوتية ومرئية.
- 🔒 التواصل داخل غرف خاصة وآمنة.

 الهدف الأساسي:

 > **جعل اللغة غير مؤثرة في قدرة الأشخاص على التواصل.**

 # ✨ المزايا الرئيسية

 ## 🔐 نظام مصادقة آمن

 يوفر LinguaBridge بنية مصادقة متكاملة تشمل:

 - إنشاء حساب جديد.
- تسجيل الدخول والخروج.
- تغيير كلمة المرور.
- جلسات آمنة باستخدام HttpOnly Cookies.
- تخزين معرفات الجلسات بعد تجزئتها.
- إمكانية إلغاء الجلسات.
- تشفير كلمات المرور باستخدام PBKDF2-SHA256.
- تحديد معدل محاولات تسجيل الدخول والعمليات الحساسة.
- حماية HTTP Headers.
- Content Security Policy.
- استخدام Parameterized SQL Queries.
- عدم إرسال التجزئات أو الأسرار الحساسة إلى المتصفح.

 الأمان جزء أساسي من التصميم وليس إضافة لاحقة.

 - 🌍 الدولة.

- 🤖 الكشف التلقائي عن اللغة.
- 📝 طريقة عرض الترجمة.
- 👁️ إظهار النص الأصلي.
- 🔊 مستوى صوت الصوت الأصلي.
- 🔊 مستوى صوت الصوت المترجم.

```
المتحدث
   ↓
تحويل الكلام إلى نص
   ↓
اكتشاف اللغة
   ↓
الذكاء الاصطناعي
   ↓
الترجمة
   ↓
لغة المشارك
   ↓
نص + صوت
```

 وبذلك يمكن لعدة أشخاص التحدث بلغات مختلفة داخل نفس الاجتماع، بينما يحصل كل شخص على تجربة مخصصة بلغته.
