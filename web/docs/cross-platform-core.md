# نواة LinguaBridge المشتركة

تعتمد نسخة الويب المتجاوبة كمرجع لتجربة المنتج: تدفق الدعوة، ردهة اللغة والموافقة، غرفة الاجتماع، المحضر، السجل، والإعدادات. تُنقل هذه العقود إلى تطبيقَي iOS وAndroid عبر واجهة خادمية واحدة، ونموذج بيانات موحّد، وتسميات لغات وحالات متطابقة.

| الطبقة | ما يُعاد استخدامه | ملاحظة تطبيقية |
| --- | --- | --- |
| العقد الخادمي | جلسات tRPC، رموز الدعوة، التفضيلات، المحاضر، والموافقات | يصبح API واحدًا للويب والجوال بعد إضافة عميل جوال مناسب |
| نموذج البيانات | الجلسات والمشاركون والمقاطع والرسائل والمحاضر | تستخدم جميع المنصات نفس معاني الحالة واللغة والموافقة |
| نظام التصميم | النبرة، الألوان، التسلسل، حالات الخصوصية، والعناصر النصية | يُترجم إلى مكوّنات React Native بدلاً من إعادة نسخ منطق التجربة |
| الصوت | اختيار الجهاز، النسخ الحي، وقراءة الترجمة | تتبدل واجهة الجهاز محليًا حسب Web أو iOS أو Android مع الحفاظ على التدفق نفسه |

لا تعتمد النسخة الأصلية للجوال على CSS أو عناصر DOM من الويب. الذي يُعاد استخدامه هو **العقد والمعاني والتدفقات ومواصفات التصميم**؛ أما العرض والتقاط الصوت فينفذان بمكوّنات أصلية مناسبة لكل نظام تشغيل.

يُنفَّذ التطبيق الأصلي في مشروع Expo مستقل لضمان أن صلاحيات الميكروفون، الصوت، الإشعارات، ومناطق الأمان تخضع لضوابط iOS وAndroid الصحيحة.
