# LinguaBridge — حالة النسخة الأولية وخارطة الجاهزية الإنتاجية

## ما نُفذ في النسخة الأولية

تقدّم LinguaBridge تجربة ويب عربية متجاوبة تشمل إنشاء الجلسة، رابط الدعوة، اختيار لغات الحديث والعرض، الموافقة الصريحة على الحفظ، سجل الجلسات، الإعدادات الشخصية، واجهة النص والترجمة، محادثة قابلة للمراجعة قبل الإرسال، قراءة الترجمة بصوت المتصفح، ردهة لاختيار الأجهزة واختبار الميكروفون، ومحضر قابل للطباعة. تنظم قاعدة البيانات الجلسات والمشاركين والنصوص والرسائل والمحاضر والتفضيلات، وتقيّد حفظ المقاطع وتوليد المحضر بموافقة المشاركين الحاضرين.

| المجال | حالة النسخة الأولية | الحد الحالي |
| --- | --- | --- |
| الدعوات والحسابات | متاحان عبر رابط رمز دعوة وحساب محمي | يلزم إضافة أدوار فريق وإدارة دعوات منتهية الصلاحية |
| الترجمة والتلخيص | مسارات خادمية آمنة للنص والمحضر | يلزم إعداد حدود استهلاك ومراقبة جودة وتقييم لغات فعلي |
| النسخ الحي | يعتمد على واجهة التعرّف الصوتي في المتصفح | تختلف التغطية والدقة حسب المتصفح؛ يلزم مسار خادمي صوتي موحّد للإنتاج |
| الصوت والأجهزة | اختيار الأجهزة واختبار الإذن وقراءة صوتية من المتصفح | إخراج الصوت الخاص بالتطبيق يحتاج قدرة أصلية مختلفة حسب المنصة |
| الاتصال متعدد المشاركين | الواجهة والحالات والعقود جاهزة | يلزم مزود WebRTC/SFU وقناة إشارات آنية قبل مكالمات إنتاجية حقيقية |
| iOS وAndroid | مواصفات مشتركة وعقد خادمي موحد موثقة | يلزم إنشاء مشروع Expo أصلي واختبار صلاحيات الصوت والإشعارات لكل منصة |

## خارطة طريق الجاهزية

| المرحلة | النتيجة | معيار القبول |
| --- | --- | --- |
| 1. اتصالات آنية | ربط غرفة الاجتماع بمزود WebRTC/SFU وقناة إشارات مستمرة | يشارك 2–10 مستخدمين الصوت والنص مع إعادة اتصال سليمة |
| 2. صوت إنتاجي | التقاط صوت، نسخ مدعوم خادميًا، وتفويض أصوات TTS حسب اللغة | قياس زمن وصول ودقة لكل لغة مستهدفة قبل الإطلاق |
| 3. تطبيقات أصلية | تطبيق Expo لـ iOS وAndroid يستهلك عقود الجلسات والمواصفات المشتركة | اختبار أجهزة فعلية وصلاحيات الميكروفون والإشعارات والاتصال الضعيف |
| 4. أمان وإدارة | أدوار فريق، سجلات تدقيق، حذف منظم، وسياسات احتفاظ | اختبار قبول الخصوصية والتفويض وحذف البيانات من طرف إلى طرف |
| 5. الإطلاق المراقب | مؤشرات صحة وقياس أخطاء وجودة ترجمة وحدود تكلفة | مجموعة تجريبية مغلقة مع مراجعة أسبوعية للأداء والجودة |

> لا ينبغي وصف النسخ أو الترجمة في المتصفح بأنها خدمة اجتماعات إنتاجية متعددة المشاركين قبل إضافة طبقة الاتصال الآني وإجراء اختبارات جودة وصوت على الأجهزة واللغات المستهدفة.
