# برنامج LinguaBridge التجريبي بلا تكلفة

## الهدف والنطاق

هذا البرنامج يختبر التجربة الأساسية قبل شراء بنية اتصال حي أو خدمات صوتية مدفوعة. لا يُعد المشاركون بزمن تشغيل أو دقة أو دعم تجاري، ولا تُستخدم نتائجهم للتسويق من دون موافقة منفصلة. الهدف هو معرفة أين يفشل المسار الفعلي: الدخول، الإذن بالصوت، اللغة، النص المترجم، المحضر، والخصوصية.

> قاعدة البيانات: لا تجمع رقم هاتف أو بريدًا أو تسجيلًا صوتيًا أو محتوى اجتماع فعلي إلا إذا اختار المشارك ذلك صراحة ضمن استخدامه الطبيعي للتطبيق. يكفي نموذج ملاحظات يدوي مجهول أو معرّف اختبار اختياري.

## عينة الاختبار

يبدأ البرنامج بـ **5 إلى 10 مشاركين**، موزعين قدر الإمكان على أجهزة وشبكات مختلفة. لا يختبر كل شخص كل الحالات؛ المطلوب تغطية المصفوفة جماعيًا لا إرهاق مشارك واحد.

| البعد | حد أدنى للتغطية | ما يوثق |
|---|---|---|
| المنصة | متصفح سطح مكتب + Android فعلي + iOS فعلي عند توفره | اسم المنصة وإصدار النظام والمتصفح فقط. |
| الشبكة | Wi-Fi + بيانات جوال | نوع الشبكة، لا اسم الشبكة أو عنوان IP. |
| الصوت | ميكروفون الجهاز + سماعة أو بلوتوث إن توفرت | هل ظهر الإذن وهل نجح اختبار المستوى. |
| اللغة | العربية/الإنجليزية أولًا، ثم لغة إضافية مطلوبة فعلًا | زوج اللغات، لا نص المحادثة بالكامل. |
| الدور | منظم + مشارك من رابط دعوة | هل اكتمل التدفق وموضع الخطأ إن وجد. |

## سيناريوهات الاختبار

| المعرف | السيناريو | معيار القبول المبدئي | البيانات المسموح بتسجيلها |
|---|---|---|---|
| B-01 | تسجيل الدخول وفتح الصفحة الرئيسية | يعود المستخدم إلى جلسة صالحة أو يرى رسالة خطأ مفهومة. | نجح/فشل، المنصة، وصف قصير. |
| B-02 | إنشاء اجتماع واختيار لغتين | تُحفظ اللغة المختارة وتظهر بالمحاذاة والاتجاه المناسبين. | زوج اللغات، نجح/فشل. |
| B-03 | مشاركة رابط دعوة والانضمام | يصل المشارك للردهة ولا يرى بيانات اجتماع آخر. | نجح/فشل، نوع الرابط. |
| B-04 | الموافقة وبدء الجلسة | لا يبدأ الحفظ قبل الموافقة الواضحة. | نجح/فشل، لا يسجل محتوى الاجتماع. |
| B-05 | اختبار الميكروفون | يطلب المتصفح الإذن بوضوح ويعرض التطبيق حالة مفهومة عند القبول أو الرفض. | جهاز الإدخال عام، نتيجة الإذن. |
| B-06 | نص أو ترجمة قصيرة غير حساسة | يظهر الأصل والترجمة بمحاذاة صحيحة. استخدم جملة اختبار غير خاصة. | اللغة، ملاحظة جودة رقمية 1–5. |
| B-07 | إنشاء محضر ومراجعته | يظهر المحضر ويمكن مشاركته أو تصديره من دون كشف جلسات أخرى. | نجح/فشل، لا نص المحضر. |
| B-08 | تنزيل بيانات الحساب | التنزيل يقتصر على الحساب والتفضيلات وسجل المشاركة الخاص بالمستخدم. | نجح/فشل فقط. |
| B-09 | الواجهة RTL/LTR | لا يتراكب النص أو يختفي عند التحويل بين العربية والإنجليزية والفرنسية. | لقطة شاشة اختيارية خالية من معلومات شخصية. |
| B-10 | انقطاع الشبكة ثم العودة | تعرض الواجهة حالة مفهومة ولا تتظاهر بأن الاتصال الحي مضمون. | نوع الشبكة، النتيجة، الزمن التقريبي. |

## نموذج ملاحظات للمختبر

يُرسل هذا النموذج يدويًا أو عبر أداة يوافق عليها المالك. لا تُرسل تسجيلات أو كلمات مرور أو رموز دخول أو محاضر حقيقية.

| الحقل | مثال مقبول |
|---|---|
| معرّف اختبار اختياري | `pilot-03` |
| المنصة | Android 15 / Chrome، أو iPhone / Safari، أو Windows / Chrome |
| نوع الشبكة | Wi-Fi أو بيانات جوال |
| السيناريو | `B-05` |
| النتيجة | نجح / فشل / نجح مع ملاحظة |
| سهولة الاستخدام | من 1 إلى 5 |
| وصف قصير | “ظهر طلب الإذن ثم نجح اختبار الميكروفون” |
| هل تسمح باستخدام هذه الملاحظة لتحسين المنتج؟ | نعم/لا |

## فرز النتائج

| التصنيف | التعريف | الإجراء |
|---|---|---|
| حاجب إطلاق | يمنع الدخول أو الموافقة أو خصوصية البيانات أو إتمام اجتماع أساسي. | يوقف التوسع ويُصلح قبل أي اختبار جديد واسع. |
| حرج | يفشل الصوت أو النص أو المحضر لمعظم الحالات المختبرة. | إصلاح وإعادة اختبار على جهاز وشبكة مختلفين. |
| مهم | تجربة مربكة أو خطأ في اتجاه النص أو إعدادات اللغة دون فقد البيانات. | يوضع في الإصدار التالي مع اختبار انحدار. |
| تحسين | اقتراح بصري أو صياغة أو راحة استخدام. | يراجع بعد معالجة العيوب الحاجبة والحرجة. |

## قرار المرحلة التالية

بعد جمع نتائج من 5 إلى 10 مشاركين، يُتخذ القرار وفق الدليل لا الحدس:

1. إذا كانت أغلب الإخفاقات في الإذن أو الأجهزة، تكون الأولوية لتحسين تجربة الجوال وإرشاد الأذونات.
2. إذا فشل الاتصال عبر الشبكات، تُقيّم حاجة TURN/SFU ولا تُشترى قبل معرفة حجم الاستخدام المتوقع.
3. إذا كانت الملاحظات عن الدقة أو التأخير، يُبنى ملف تقييم لغوي قبل زيادة عدد اللغات أو شراء دقائق صوت.
4. إذا كانت المسارات الأساسية مستقرة، يبدأ تدقيق الإتاحة والأمان ثم تجربة فريق/شركة محدودة.
