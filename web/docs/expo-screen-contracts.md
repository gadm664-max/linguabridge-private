# عقود شاشات تطبيق LinguaBridge الأصلي

| الشاشة | الإدخال | الخدمة المشتركة | المخرج |
| --- | --- | --- | --- |
| البداية | حساب المستخدم | `meetings.history` | جلسات حديثة وزر بدء/انضمام |
| الردهة | اللغات والصوت والموافقة | `meetings.create` | رمز دعوة وانتقال للغرفة |
| الانضمام | رمز الدعوة والتفضيلات | `meetings.byInvite` و`meetings.join` | مشارك فعال في الجلسة |
| الغرفة | نص وصوت وتفضيلات العرض | `translation.translateText` و`meetings.saveSegment` | نص أصلي وترجمة ومحفوظات مقيدة بالموافقة |
| المحضر | رمز الدعوة | `minutes.get` و`minutes.generate` | ملخص ونقاط وإجراءات قابلة للتصدير |
| الإعدادات | التفضيلات | `meetings.preferences.get/save` | لغة وصوت وخصوصية محفوظة |

تستهلك واجهات Expo قائمة `supportedLanguages` وأعلام الخصوصية من `shared/meetingSpecs.ts`. وتستخدم صلاحية الميكروفون الأصلية وسجل الصوت الخاص بالنظام بدلاً من Web Speech API.
