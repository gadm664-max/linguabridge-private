# موجز تنفيذ تطبيق LinguaBridge للجوال

سيُنفّذ التطبيق الأصلي باستخدام Expo وReact Native، مع شاشات: بداية، ردهة، غرفة اجتماع، محضر، سجل، وإعدادات. تستفيد النسخة من عقود الجلسات ومواصفات اللغات المشتركة، وتستخدم الميكروفون والصوت ومناطق الأمان الخاصة بالنظام بدلاً من واجهات المتصفح.

يجب أن يملك كل زر رد فعل لمسيًا وحالة تحميل أو خطأ، وأن يُختبر تدفق الدخول والدعوة والميكروفون على جهازَي iOS وAndroid فعليين. تُعامل طبقة الاجتماع الجماعي والصوت متعدد الأطراف كتجهيز خلفي إنتاجي يتم وصله لاحقًا بمزود اتصال آني مناسب.
